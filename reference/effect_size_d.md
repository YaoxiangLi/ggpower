# Compute Cohen's d from means and standard deviation

Compute Cohen's d from means and standard deviation

## Usage

``` r
effect_size_d(mean_h1, mean_h0 = 0, sd)
```

## Arguments

- mean_h1:

  Mean assumed under H1.

- mean_h0:

  Mean assumed under H0 or comparison group mean.

- sd:

  Common standard deviation.

## Value

Numeric effect size d.
